# mmagix-files · 产品顶层设计

> 一页核心版。全文见《方案设计.md》（V1.2 · 2026-10-08 评审修订版）。

## 一句话

**无用户体系的可嵌入 web 文件中台——纯前端，0 后端**：一个静态 SPA 扔上 CDN，消费方一行 iframe，即得 Windows 目录式的文件管理/预览/编辑工作台。

## 解决什么

产品要嵌文件管理，市面没有合身开源品：filestash/Nextcloud 带一整套用户体系与部署面，纯前端 S3 browser 只有玩具级零件。**「即开即用 + 宿主说了算 + 零服务部署」这个生态位是空的**——mmagix-files 占它。

## 五支柱（不可妥协项）

| 支柱 | 含义 |
| --- | --- |
| **iframe / open 即插** | 双嵌入形态：iframe 内嵌或 window.open 独立窗（等效，JSSDK 自动适配）；URL fragment 传全量配置 JSON，嵌入即用；行为/外观/功能/后端全部宿主可配 |
| **单文件模式** | URL 也可只开**一个文件**：`#file={ v, source:{url, method:GET\|POST}, save? }`——只读=无 save 段，可写=带 save 回写；源 URL 支持 **GET/POST**（POST 体/头可配）——不做目录，纯查看/编辑组件 |
| **无用户体系·0 后端** | 会话=**凭证 TTL 定长**（执法线=凭证 TTL 服务侧硬线；前端定时自毁=UX 线，非安全线），无 redis、无会话服务、退出即无痕；「URL 即凭证」 |
| **S3 数据面** | 消费方给 URL+**scoped 短 TTL 凭证**（接入硬义务），浏览器直签 SigV4、直传字节；中台不碰数据 |
| **JSSDK 100%** | postMessage 全量开放，宿主可操控 iframe 内一切；应用可经插件注册扩展 |

## 架构一根线

```
宿主 ──iframe / window.open──> Vue3 SPA(CDN 静态) ──SigV4──> S3 兼容端点(直传)
        ├ #config={...} 工作台模式（全量配置）
        └ #file={ v, source:{url, method:GET|POST}, save? } 单文件模式（只读=无 save 段；数据源=普通 HTTP，非 S3 也可）
```

**没有第二个方块。** 会话服务（ticket 一次性+心跳延期+审计）=未来可选增强件，挂前端凭证获取接口，架构不为它分叉。

## 核心场景（消费方接入三步）

1. 准备 S3 端点+**scoped 短 TTL 凭证**（OSS STS/MinIO STS，prefix 限定到会话目录） → 2. 拼配置 JSON 进 fragment → 3. `<iframe src="...#config={...}">` 或 `window.open(...)`，完事。

**单文件场景**：`<iframe src="...#file={ v, source:{url, method:GET|POST}, save? }">`——一个文件一个查看器/编辑器（只读=无 save 段），无目录无 S3 也能接（普通 HTTP 源，POST 拉取、可配置回写保存）。

## 边界（做什么 / 不做什么）

- ✅ 做：目录树、多 tab 打开、上传/下载/重命名/删除、内置应用（图/文/代码/md/pdf/音视频/CSV）、Monaco 代码编辑、主题 OEM 中英文、插件注册
- ❌ 不做：任何自有后端、用户/权限体系（宿主的活）、数据中转、**office 编辑**（v1 只预览 docx/xlsx；pptx 预览降级下载；Collabora 备档候需求）、服务端转码
- ⚠️ 代价认领：凭证进浏览器（防线=scope+短 TTL，XSS 即失守）· 会话定长不延期 · URL 在凭证 TTL 内可重放

## 竞争位

filestash（AGPL/重平台）· Quantum（无 S3）· Amplify Browser（React 组件非产品）——**全是零件或重平台，无一是「即开即用嵌入件」**。纯自研，参考 Apache-2.0 双件抄形，filestash 只看思路（AGPL 红线）。
