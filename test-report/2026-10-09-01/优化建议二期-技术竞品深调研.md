## 〇、四产品速览

| 产品 | 定位 | 形态 | 与我们的关系 |
|---|---|---|---|
| FileBrowser Quantum | 单二进制自托管文件管理器，SQLite 索引做到「本地资源管理器级」搜索与列表 | Go 后端 + Vue3 壳（原版 2026-09 归档，此为 gtsteffaniak 接班 fork，纯社区） | 同类竞品（有后端），其搜索/上传/键盘流是最佳对标 |
| Filestash | 浏览器里的「任意存储通用客户端」，一切皆插件，20+ 后端聚合 | Docker 自托管，Go+自研前端框架（插件=构建期编译） | 理念同源（凭据不落服务端），连接向导/编辑器即插件值得抄 |
| Amplify UI Storage Browser | AWS 官方组件级 S3 浏览器（React 可嵌入） | Connected Component + headless store | **同类竞品（同为 S3 直连）**，最有逐条对照价值 |
| OpenVSCode | VS Code 工作台上浏览器（Server=远程内核 / vscode.dev=纯前端） | WebSocket+Monaco 全家桶 | 只借工作台交互（tab/状态栏/降级/命令面板），不借 IDE |

## 二、FileBrowser Quantum 详报

**亮点**（★★★=强对标价值）：SQLite 索引秒搜+高级搜索面板★★★；上传分块/暂停恢复/断点续传/`Ctrl+V` 粘贴上传★★★；成体系键盘流（Alt+↑/↓、字母跳转、Ctrl+滚轮密度）★★★；预览细节密度（缩略图占位/Quick Jump/HEIC/歌词/字幕/3D）★★★；3+2 视图+记住每文件夹视图排序/框选/面包屑可拖放★★。

**六条建议**：①IndexedDB 元数据索引+全局搜索（P0 3~5）②上传体验包（P0 5~8）③键盘流（P1 2~3）④大列表两段式+目录大小+状态栏（P1 3~4）⑤预签名分享生成器（P1 2~3）⑥预览细节包插件化（P2 1~2/项）。

**不适合抄**：SQLite/watcher/WebDAV 服务端（→IndexedDB 等价）；OIDC/LDAP/TOTP（服务端认证域，我们是用户自带凭据）；OnlyOffice（需回调后端）；服务端缩略图/ffmpeg/归档流；分享计数/限速/配额（需服务端记账）。

## 三、Filestash 详报

**亮点**：连接向导（类型表单/自动补全/测试连接/免输入登录，凭据只存浏览器）★★★；插件分类学（backend/auth/editor/config/middleware）★★★；编辑器集广度（org-mode/表单渲染器/PSD…100 格式）★★★；分享细粒度★★；「编辑器即插件」清单式扩展打法★★。

**六条建议**：①连接向导+多 Profile（P0 3~5）②iframe 免输入接入（**已具备**，见「勿重复」）③编辑器插件注册表（P1 协议 1~2）④结构化表单渲染器（P2 3~4）⑤分享只读门户受限版（P2 4~6）⑥单格式工具页引流（P2 1~2/页）。

**不适合抄**：20+ 后端抽象（S3-only 是差异化）；Go 编译式插件/Admin Console（我们运行时动态加载形态更先进）；LDAP/OIDC/SAML；服务端转码；分享服务端权限（无后端无法分发后约束）。

## 四、Amplify UI Storage Browser 详报

**亮点**：Location 一等模型（bucket+prefix+permissions 打包）★★★；权限驱动动作可见性（禁用+提示而非隐藏/inaccessible 占位）★★★；千条语义分页★★★；覆盖冲突确认★★★；统一传输详情（进度/取消/重试/concurrency）★★★；浏览器端流式 zip 文件夹下载★★；跨位置 copy★★；displayText 文案包+headless store 分离（白标定制靠文案包）★★。

**六条建议**：①传输任务中心（P0 3~4）②覆盖冲突确认（P0 2）③Location 多位置（P1 3~4）④千条分页+跳页（P1 1~2）⑤无权限动作可见性规则（P1 1）⑥跨前缀 multipart copy（P2 3~4）。

**不适合抄**：Cognito/IAM/Access Grants 接入层（凭证由宿主注入）；Design Token 主题（已有 Fc* 链路）；React hooks/slots API（技术栈异构）。

## 五、OpenVSCode 详报

**亮点**：Tab 预览态（斜体=预览，双击钉住——文件管理器最值得抄的单个交互）★★★；只读双轨降级（黄条幅+徽章+保存禁用，界面照常可用）★★★；状态栏信息密度（常驻一行、各段可点击）★★★；命令面板三件套（模糊匹配/最近置顶/双模式/keybinding 提示）★★★；快捷键即数据+冲突检测★★；大文件策略（阈值确认/自动降级/防崩）★★★（对纯前端 SPA 同构痛点）。

**六条建议**：①只读降级双轨（P0 1~2）②状态栏常驻（P0 2）③预览 tab 化+钉住（P1 2~3）④命令面板升级（P1 1~2）⑤大文件分级打开（P0 1~2）⑥本地设置面板（P2 2）。

**不适合抄**：Monaco 全家桶/远程扩展宿主/WebSocket 后端（重且与 0 后端定位冲突）；File System Access API（Chromium-only 且与 S3 直连正交）；LSP/调试器；自研树虚拟化（Element Plus+pinia 够）；extension host（我们动态插件更轻，反向优势）。
